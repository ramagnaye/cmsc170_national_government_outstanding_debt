Debt Ahead

Predicting whether the Philippine National Government’s outstanding debt will rise next month using historical debt trends.

Problem Statement & Motivation

The Philippine National Government's outstanding debt changes from month to month. This project uses monthly debt records from January 1993 to September 2025 to examine whether recent changes in domestic, external, and total debt, together with the calendar month, can help predict whether total outstanding debt will increase the following month.

Problem Statement

How well can we predict whether total outstanding debt will rise next month, and do the models perform better than simply predicting an increase every month or using the most recent debt trend?

We compare K-Nearest Neighbors, Naive Bayes, and the Perceptron, implemented using NumPy, against two baselines. We train the models on the earlier records and test them on the later records without shuffling. We compare accuracy, macro F1, and F1 for each class to see how well the methods handle both increases and months without an increase.

Dataset Description

Source
The data in debt_monthly_1993-2025.csv were extracted from the PDF Outstanding Debt – September 2025 (Current Year Monthly), available on the BetterGov dataset page. The CSV contains monthly records from January 1993 to September 2025.
Size and Coverage
The CSV contains 393 monthly records from January 1993 to September 2025. Each record contains the year, month, month number, domestic debt, external debt, and total outstanding debt. Debt amounts are recorded in millions of Philippine pesos. After preprocessing, 391 labeled samples remain.
Input Features
  • Percentage change in domestic debt from the previous month
  • Percentage change in external debt from the previous month
  • Percentage change in total outstanding debt from the previous month
  • Calendar month encoded as an integer from 1 to 12
Target
The target is 1 if total outstanding debt increases from the current month to the following month, and 0 if it stays the same or decreases.

Preprocessing Steps

  1. Arrange the monthly records in chronological order.
  2. Compute the percentage change from the previous month for each debt series.
  3. Compare current-month and following-month total debt to assign the target.
  4. Exclude the first month because it has no previous observation and the last month because it has no following observation.
  5. Standardize the inputs for KNN and the Perceptron using means and standard deviations calculated from the training set. Naive Bayes uses the original feature values.

Methods

K-Nearest Neighbors (KNN)

KNN finds the 21 closest training samples using Euclidean distance across the four standardized features.

Euclidean distance. d(z, zi) = √[Σj=14 (zj − zij)2]

Here, z is the input sample and zi is a training sample. KNN predicts the majority class among the 21 neighbors.

Naive Bayes

Naive Bayes scores each class using its frequency in the training data, the calendar month, and the three debt percentage changes.

Class score. S(c) = ln P(c) + ln P(m | c) + Σj=13 ln fcj(xj)

P(c) is the prior probability of class c, P(m | c) is the Laplace-smoothed probability of calendar month m within that class, and fcj is the Gaussian density for debt-change feature j. The model predicts the class with the higher score.

Perceptron

The Perceptron classifies each sample using a weighted sum of its standardized features.

Decision score. s = w · z + b. Predict 1 if s > 0 and 0 otherwise.

When it makes a mistake during training, it updates the weights w and bias b using a learning rate of 0.1. It trains for up to 200 epochs and keeps the weights and bias that produced the fewest training errors.

Baselines

  • Always up. Predicts an increase every month.
  • Last-month trend. Predicts an increase if total debt rose from the previous month to the current month.

Experimental Setup

Data Split

The 391 labeled samples were split chronologically, with the first 313 used for training and the last 78 used for testing. The data was split approximately 80/20 without shuffling.

Evaluation Metrics

The comparison reports accuracy, macro F1, and separate F1 scores for the increase and no-increase classes. Macro F1 gives equal weight to both classes by averaging their F1 scores. Confusion matrices show how many samples each model classified correctly or incorrectly for each class.

Model Settings

  • KNN. Used 21 neighbors with Euclidean distance. The value was selected from 1, 3, 5, 7, 11, 15, and 21 based on accuracy on the last 20% of the training set.
  • Naive Bayes. Applied add-one Laplace smoothing to the 12 calendar month categories. Added 10−9 to each Gaussian variance estimate to avoid division by zero.
  • Perceptron. Used a learning rate of 0.1, a maximum of 200 epochs, and a random seed of 0 to shuffle the training samples each epoch.
